# ระบบแสดงรายงานประจำเดือน (การประปานครหลวง - MWA) แบบ iframe พร้อมระบบจัดการหลังบ้าน

โปรเจกต์นี้พัฒนาขึ้นสำหรับนำไปฝัง (`iframe`) ในเว็บไซต์หลักของการประปานครหลวง โดยฝากไฟล์ทั้งหมดไว้บน **GitHub Pages** สามารถเปิดดูรายงานแยกตามปี เลือกดู 12 เดือน และมีหน้าจัดการหลังบ้าน (`admin.html`) สำหรับเปลี่ยนลิงก์หรือเพิ่มปีใหม่ได้ง่ายๆ

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์

| ชื่อไฟล์ | คำอธิบาย |
| :--- | :--- |
| **`index.html`** | หน้าหลักสำหรับนำไปฝังใน `<iframe>` (แสดงตัวกรองปี, ปุ่ม 12 เดือน และลิงก์ดาวน์โหลดรายงาน) |
| **`admin.html`** | หน้าจัดการลิงก์หลังบ้าน (จัดการ 12 เดือน, เปิด/ปิดสถานะ, เพิ่มปีใหม่, อัปเดตขึ้น GitHub หรือดาวน์โหลด `data.json`) |
| **`data.json`** | ฐานข้อมูลกลาง (เก็บรายการปี และลิงก์ของแต่ละเดือน) |
| **`embed-preview.html`** | หน้าจำลองการฝัง `iframe` ใต้ภาพแบนเนอร์จริงของการประปานครหลวง (ใช้ทดสอบการแสดงผล) |
| **`banner.jpg`** | ภาพแบนเนอร์ "รายงานประจำเดือน" สำหรับหน้าจำลอง |

## 🚀 ขั้นตอนที่ 1: การนำขึ้น GitHub และเปิด GitHub Pages

1. **สร้าง Repository บน GitHub:**
   - เข้า GitHub -> กด **New repository**
   - ตั้งชื่อคลัง เช่น `mwa-monthly-reports` (เลือกเป็น **Public**)
2. **อัปโหลดไฟล์ทั้งหมดขึ้น GitHub:**
   - อัปโหลดไฟล์ `index.html`, `admin.html`, `data.json` และไฟล์รูปภาพขึ้นไปที่ branch `main`
3. **เปิดใช้งาน GitHub Pages:**
   - ไปที่ **Settings** ของ Repository -> เลือกเมนู **Pages** ด้านซ้าย
   - ที่หัวข้อ **Build and deployment > Branch**: เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
   - รอ 1-2 นาที คุณจะได้ URL เว็บไซต์ เช่น:
     ```
     https://looknamx.github.io/mountly-report/index.html
     ```

## 💻 ขั้นตอนที่ 2: นำโค้ด iframe ไปติดบนเว็บไซต์หลัก

นำโค้ดด้านล่างนี้ไปวางในระบบ CMS หรือไฟล์ HTML ของเว็บไซต์หลักในตำแหน่งใต้แบนเนอร์:

```html
<!-- ฝังระบบรายงานประจำเดือน -->
<iframe 
  id="mwaMonthlyReport"
  src="https://looknamx.github.io/mountly-report/index.html" 
  width="100%" 
  height="750" 
  style="border: none; overflow: hidden; width: 100%; max-width: 1200px; display: block; margin: 0 auto;" 
  title="รายงานประจำเดือน การประปานครหลวง"
  loading="lazy">
</iframe>

<!-- (ทางเลือกเสริม) สคริปต์ปรับความสูง iframe อัตโนมัติ ไม่ให้มี scrollbar ซ้อนกัน -->
<script>
  window.addEventListener('message', function(e) {
    if (e.data && e.data.type === 'mwa-iframe-resize') {
      var iframe = document.getElementById('mwaMonthlyReport');
      if (iframe && e.data.height) {
        iframe.style.height = (e.data.height + 20) + 'px';
      }
    }
  });
</script>
```

> **เคล็ดลับระบุปีล่วงหน้า:**  
> หากต้องการเปิดหน้าเว็บโดยให้เลือกปีนั้นๆ ทันที สามารถใส่ query string ได้ เช่น:  
> `index.html?year=2568` หรือ `index.html?year=2567`

## ⚙️ ขั้นตอนที่ 3: การใช้งานหน้าจัดการหลังบ้าน (`admin.html`)

เปิดเข้าหน้า `admin.html` (เช่น `https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/admin.html`):

1. **เลือกปี / เพิ่มปีใหม่:**
   - เลือกปี พ.ศ. จากกล่อง Dropdown ด้านบน
   - หากต้องการเริ่มปีงบประมาณ/ปีปฏิทินใหม่ ให้กดปุ่ม **"+ เพิ่มปีรายงานใหม่"** (ระบบจะสร้างเทมเพลต 12 เดือนให้ทันที)
2. **จัดการลิงก์รายงานประจำเดือน:**
   - วาง URL ลิงก์ (เช่น ลิงก์ไฟล์ PDF, Google Drive หรือหน้าเว็บประกาศ) ในช่องของเดือนนั้นๆ
   - สวิตช์ **"สถานะ"**: 
     - **เปิด (สีเขียว)** = แสดงปุ่มให้ประชาชน/เจ้าหน้าที่คลิกเปิดอ่านได้
     - **ปิด (สีเทา)** = ขึ้นสถานะ "รอการเผยแพร่" (ยังไม่เปิดให้คลิก)
   - กดไอคอน **ลูกศรเปิด** ทางขวาเพื่อทดสอบว่าลิงก์เปิดได้ถูกต้องหรือไม่
3. **การบันทึกข้อมูล (มีให้เลือก 2 วิธีสะดวก):**
   - **วิธีที่ 1: บันทึกขึ้น GitHub ทันที (Auto Commit via API)**
     - ใส่ **GitHub Personal Access Token (PAT)** และชื่อ **Repository** (ระบบจะจำไว้ในเครื่อง ไม่ต้องพิมพ์ซ้ำ)
     - กดปุ่ม **"บันทึกและ Commit ขึ้น GitHub ทันที"** ข้อมูลจะถูกอัปเดตไปยังหน้าเว็บทันที 100%
   - **วิธีที่ 2: ดาวน์โหลดไฟล์ `data.json`**
     - หากไม่ต้องการใช้ Token ให้กดปุ่ม **"ดาวน์โหลด data.json"**
     - จากนั้นนำไฟล์นี้ไปลากวาง (Drag & Drop) หรืออัปโหลดทับไฟล์เดิมบนหน้าเว็บ GitHub ได้ทันที

## 🎨 จุดเด่นของการออกแบบ
- **ธีมสีองค์กรการประปานครหลวง (MWA Blue & Cyan):** ออกแบบด้วยสีน้ำเงิน-ฟ้าสะอาดตา ดูเป็นทางการ ทันสมัย ใช้งานง่าย
- **Responsive 100%:** รองรับการแสดงผลทุกหน้าจอ ไม่ว่าจะเป็น Desktop, Tablet หรือ Smartphone
- **ไม่มี Dependency หลังบ้าน:** ทำงานแบบ Static File ไม่ต้องเช่า Server หรือฐานข้อมูล ค่าใช้จ่ายเป็น 0 บาท
