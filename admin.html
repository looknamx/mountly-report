ลำดับ เดือน ลิงก์รายงาน (URL ลิงก์ PDF / หน้าเว็บ) สถานะ ทดสอบ

อัปเดตขึ้น GitHub อัตโนมัติ (GitHub API)

หากตั้งค่า Personal Access Token ไว้ คุณสามารถกดบันทึกและให้ระบบ commit ไฟล์ data.json เข้า GitHub Repository ได้ทันที โดยไม่ต้องพิมพ์คำสั่ง Git

ดาวน์โหลดไฟล์ data.json เพื่ออัปโหลดเอง

หากไม่ต้องการเชื่อมต่อ Token คุณสามารถกดดาวน์โหลดไฟล์ data.json แล้วนำไปวางทับใน GitHub Repository หรือเซิร์ฟเวอร์ได้โดยตรง
